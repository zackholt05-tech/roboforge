Chronological record of every executed experiment or engineering check. Results are
recorded as observed, including failures.
- Sessions 0–2 ran engineering checks only. Session 2's random and no-op rollouts are sanity
  checks of the apparatus, not research results.
- Session 3 ran the first **training runs** and **validation-only** closed-loop pilots. These
  are development numbers: one training seed, on the in-distribution validation suite, and
  selected on that same suite (RESEARCH_PROTOCOL §7). They are not held-out results. No
  held-out test state has been loaded.
- Session 4 added the conditional diffusion policy. Its Lift pilot follows the same rules:
  validation-only development numbers, one seed. Still no held-out test state has been
  loaded.
- Session 5 added the Modal integration and ran the first **paid** compute: Gate A, approval
  A-01, $0.148 billed. It ran no protocol training run and loaded no held-out test state.
  The one Modal-trained checkpoint is an engineering smoke, validated on 5 starts only.
- Session 6 ran the **Lift main suite** (24 runs, 480 canonical evaluations) on local CPU and
  the canonical container at $0. Its numbers are **validation-only development numbers**:
  checkpoints and configurations were selected on the same 50 validation starts. No held-out
